# Kişisel notlar

## Çalışma şeklim
- Yanıtları Türkçe ve kısa ver. Önce sonucu yaz, ayrıntıyı sonra.
- Yeni bir iş için önce kısa bir plan sun, onayım olmadan dosya değiştirme.
- Bir şeyden emin değilsen tahmin etme, tek bir soru sor.

## Ortamım
- Windows kullanıyorum, komutları Git Bash (bash) sözdizimiyle yaz..
- Test çalıştırırken: dotnet test çıktıyı iki cümleyle özetle.

## Tercihlerim
- Commit mesajı Türkçe, tek satır, sonunda issue numarası: "İade nedeni zorunlu (#2)".
- Yeni test dosyası oluştururken önce var olan bir test dosyasına bak, aynı yapıyı kullan.
